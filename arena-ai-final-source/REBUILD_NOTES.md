# Arena AI Android final source

This folder contains the final source needed to rebuild the latest APK.

Main changes from upstream:
- WebView download support for http/https, blob:, and data: downloads.
- Drag pull-to-refresh disabled.
- Refresh button placed at the far right of the bottom bar.
- Account switch button placed at the far left of the bottom bar.
- Bottom navigation ripple/pressed background enabled.
- Navigation sync bridge for SPA route changes.
- App launcher icon replaced with the supplied transparent SVG vector.

Build from `ArenaAI-Android` with Android Studio or Gradle using JDK 17 and Android SDK 34.
